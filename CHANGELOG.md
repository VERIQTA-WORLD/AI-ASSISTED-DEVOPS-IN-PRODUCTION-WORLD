# Changelog

This file records notable changes to AI-Assisted DevOps in Production World.

Entries describe repository changes, not completed learning outcomes or verified production deployments. Empty files and reserved folders are identified as scaffolds.

## Unreleased

### Added

- Public README with navigation tables, collection directories, and visual assets.
- 39 numbered sections covering AI-assisted engineering foundations, technical domains, review, verification, and production operations.
- 100 collection directions organized into 10 domains, preserving their original titles and numbering.
- An empty outline and `EX-001` exercise scaffold for each collection.
- A consistent nine-stage exercise structure:
  1. Problem.
  2. Evidence.
  3. Ask AI.
  4. AI response.
  5. Engineer review.
  6. Verify.
  7. Implement.
  8. Test.
  9. Production safety.
- Reserved learning files for Linux, Docker, Kubernetes, Terraform, CI/CD, cloud engineering, networking, security, observability, and reliability.
- Sections for Python, Go, Ansible, databases, caches, and web infrastructure.
- Sections for evidence collection, redaction, AI answer evaluation, retrieval, agent tool access, and AI security.
- Empty project, lab, interview, and engineer notebook structures.
- A reserved case file for investigating unexpected Terraform replacement of a production database.
- Catalogues for engineering artifacts, AI workflow records, and operational controls.
- Empty context, review, change planning, response capture, verification, redaction, and automation templates.
- Project and vendor logos, portrait covers, galleries, badges, and an engineering workflow diagram.
- Asset attribution records and catalogue metadata.

### Current limitations

- Learning notes, exercises, projects, case files, code, and configuration templates remain intentionally empty.
- Collection titles containing “50 Problems” or “100 Incidents” describe planned scope. They do not represent completed cases.
- No runnable AI integration, autonomous agent, or production deployment is included.
- Tool and vendor marks do not establish native AI functionality, endorsement, or an installed integration.
- AI-provider logos and the official VERIQTA symbol remain to be added.
