# Security policy

Do not report exposed credentials or sensitive findings in a public issue. Use a private GitHub vulnerability report if available; otherwise contact a repository maintainer privately through a contact method listed on their public profile. Do not include live secrets in a report.

Revoke an exposed credential immediately. Share only redacted evidence, affected paths, impact and reproduction details that are safe to disclose.

Educational examples must use dummy credentials, minimal permissions and isolated environments. AI output must not bypass human review or production access controls.
