# Contributing

Contribute clear explanations, operational scenarios, prompt improvements and reproducible validation methods.

1. Select the handbook or resource that matches the topic.
2. Explain the environment, assumptions and learning goal.
3. Include evidence, validation steps and expected outcomes for technical changes.
4. Include failure handling and cleanup for labs.
5. Remove secrets and private information.
6. Open a pull request describing the change and how you checked it.

AI-assisted contributions require the same technical review as other work. Verify commands and cite authoritative sources for tool-specific claims. Respect the rights of source authors. Do not submit copied paid course material, leaked exam content or private incident records.
